# FreeTune-Desktop

FreeTune is a free, lightweight desktop music client inspired by OpenTune.

- macOS first, then Windows
- Tauri 2 + Svelte + TypeScript
- GPL-3.0-or-later

## Development

```bash
npm install
npm run tauri dev
```

## Desktop build

```bash
npm run tauri build
```
